# Deploying Daykart to Vercel (Frontend) & Render (Backend)

This guide provides step-by-step instructions to deploy the **Daykart** platform: the Next.js client on **Vercel** and the Express API server on **Render**.

---

## Step 1: Push Project to GitHub
1. Create a new repository on your GitHub account.
2. Push your local workspace branch to GitHub:
   ```bash
   git add .
   git commit -m "Configure cross-domain settings and add deployment guides"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```

---

## Step 2: Deploy the Backend on Render
1. Log in to [Render](https://render.com/).
2. Click **New +** (top right) and select **Web Service**.
3. Connect your GitHub account and select your **Daykart** repository.
4. Set the following configuration parameters on the creation form:
   * **Name**: `daykart-backend`
   * **Region**: Choose the region closest to your target audience (e.g., Singapore or Oregon).
   * **Branch**: `main`
   * **Root Directory**: `backend` (⚠️ **CRITICAL**: Do not leave this blank).
   * **Runtime**: `Node`
   * **Build Command**: `npm install`
   * **Start Command**: `npm start`
5. Scroll down to **Advanced** ➔ **Environment Variables** and add the following keys:

| Key | Example Value / Description |
| :--- | :--- |
| `NODE_ENV` | `production` |
| `MONGO_URI` | `mongodb+srv://user:pass@cluster.mongodb.net/daykart?retryWrites=true&w=majority` |
| `REDIS_URL` | `redis://default:password@redis-cloud-instance:6379` |
| `ELASTICSEARCH_NODE` | `https://elastic:password@elastic-cloud-instance:9243` |
| `JWT_ACCESS_SECRET` | *(Generate a long random secure key)* |
| `JWT_REFRESH_SECRET` | *(Generate another long random secure key)* |
| `JWT_ACCESS_EXPIRES_IN` | `15m` |
| `JWT_REFRESH_EXPIRES_IN` | `7d` |
| `CLIENT_URL` | `https://daykart-frontend.vercel.app` *(update with your Vercel URL once generated)* |
| `CLOUDINARY_CLOUD_NAME` | *(Your Cloudinary cloud name)* |
| `CLOUDINARY_API_KEY` | *(Your Cloudinary API key)* |
| `CLOUDINARY_API_SECRET` | *(Your Cloudinary API secret)* |
| `SMTP_HOST` | `smtp.resend.com` *(or your SMTP server, e.g. sendgrid, ses)* |
| `SMTP_PORT` | `465` *(or 587)* |
| `SMTP_USER` | `resend` *(or your SMTP username)* |
| `SMTP_PASS` | `re_123456789...` *(your SMTP access token)* |

6. Click **Create Web Service**. Render will begin downloading and building your Express backend.

---

## Step 3: Deploy the Frontend on Vercel
1. Log in to [Vercel](https://vercel.com/).
2. Click **Add New...** ➔ **Project**.
3. Import the same GitHub repository.
4. On the **Configure Project** screen, set the following parameters:
   * **Framework Preset**: `Next.js`
   * **Root Directory**: Click **Edit** and select the `frontend` folder (⚠️ **CRITICAL**).
   * **Build and Output Settings**: Keep default settings (`npm run build` and `.next`).
   * **Environment Variables**: Add this single key:

| Key | Value |
| :--- | :--- |
| `NEXT_PUBLIC_API_URL` | `https://daykart-backend.onrender.com/api/v1` *(replace with your actual Render URL)* |

5. Click **Deploy**. Vercel will compile and optimize the Next.js bundle and provide a live URL (e.g., `https://daykart-frontend.vercel.app`).

---

## Step 4: Finalize Cross-Origin CORS Link
Because security options are configured restrictively, the backend requires an exact match for the origin requesting resources:
1. Go to your **Render Dashboard** ➔ Select your `daykart-backend` service ➔ **Environment**.
2. Update the `CLIENT_URL` environment variable to match the exact URL generated by Vercel:
   * Example: `https://daykart-frontend.vercel.app` (do not add a trailing slash `/`).
3. Save the changes. Render will automatically re-deploy the server with the new environment variables.

Now, your multi-vendor storefront is live, secure, and ready for use!
