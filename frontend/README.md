# Daykart Frontend

This is the Next.js frontend client for Daykart, a multi-vendor e-commerce platform.

## Live Deployment
- **URL**: [https://daykart.vercel.app](https://daykart.vercel.app)

## Local Development

1. Ensure the backend server is running.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the storefront.
